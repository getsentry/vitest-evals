Judges score the run that the harness already captured. Harnesses own
execution; judges own rubrics, parser logic, model calls, score thresholds, and
failure messages.

Use deterministic judges before reaching for model-scored rubrics. Put judges
at the suite level when every case should satisfy the same contract, and use
explicit judge assertions when one case needs an extra check.

## Usage

Suite-level judges run after each `run(...)`. This example keeps the same Paris
story as the harness pages and uses the built-in factuality judge.

```ts title="evals/capital.eval.ts"
import { openai } from "@ai-sdk/openai";
import { aiSdkJudgeHarness } from "@vitest-evals/harness-ai-sdk";
import { expect } from "vitest";
import {
  describeEval,
  FactualityJudge,
} from "vitest-evals";
import { qaHarness } from "./qaHarness";

const judgeHarness = aiSdkJudgeHarness({
  model: openai("gpt-4.1-mini"),
  temperature: 0,
});
const factualityJudge = FactualityJudge({
  expected: "Paris is the capital of France.",
  judgeHarness,
});

describeEval(
  "capital questions",
  {
    harness: qaHarness,
    judges: [factualityJudge],
    judgeThreshold: 0.6,
  },
  (it) => {
    it("knows the capital of France", async ({ run }) => {
      const result = await run("What is the capital of France?");

      expect(result.output).toContain("Paris");
    });
  },
);
```

## Per-Case Expectations

Suite-level judges also need case-specific expectations. Pass them as the
second `run(...)` argument. The harness never sees them; each automatic judge
receives them in its context, and `toSatisfyJudge(...)` reuses them for the
returned run unless matcher options override them.

```ts title="evals/capital.eval.ts"
import {
  describeEval,
  StructuredOutputJudge,
  ToolCallJudge,
} from "vitest-evals";
import { qaHarness } from "./qaHarness";

describeEval(
  "capital questions",
  {
    harness: qaHarness,
    judges: [ToolCallJudge(), StructuredOutputJudge()],
    judgeThreshold: 0.75,
  },
  (it) => {
    it.for([
      {
        input: "What is the capital of France?",
        expected: { answer: "Paris" },
        expectedTools: ["lookupCapital"],
      },
    ])("$input", async ({ input, ...expectations }, { run }) => {
      await run(input, expectations);
    });
  },
);
```

`judgeThreshold` compares the average score of all automatic judges, so one
judge can fall short while the case still passes. A `null` score counts as 0.
Use explicit `toSatisfyJudge(...)` assertions when each judge must pass on its
own threshold.

Keep deterministic judges close to the harness contract. Use custom judges for
rubrics that need domain-specific scoring or reusable explanations.
